# 관리자 계정 운영

- 비로그인 상태에서 기존 공용 관리자 비밀번호로 진입하면 최고 관리자 권한을 사용한다.
- 첫 관리자 계정은 공용 비밀번호로 진입한 뒤 회원 상세에서 최고 관리자 권한을 부여한다. 이후 해당 회원이 로그인하면 관리자 비밀번호 없이 진입한다.
- 최고 관리자는 모든 회원과 권한을 관리한다. 회원 관리자는 일반 회원만 관리하며, 공지 관리자는 공지만 관리한다.
- 공용 비밀번호로 수행한 기록은 개별 관리자를 식별할 수 없다. 개인별 기록을 위해 관리자 계정 사용을 권장한다.
- DB 계정에는 `admin_user_metadata`, `admin_audit_log` 테이블 생성 권한이 필요하다. 최초 요청 시 자동 생성되며 기존 회원의 가입일이 없으면 확인 불가로 표시한다.
- 정지와 해제는 기존 로그인 토큰을 무효화한다. 해제 후 다시 로그인해야 한다.
- 회원 및 권한 관리 기록은 변경과 같은 트랜잭션에 저장하고 최근 100건을 표시한다. 기록 도입 이전 작업은 표시되지 않는다.
